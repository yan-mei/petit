# Petit - A Simple Cardano Wallet Chrome Extension

## Overview

Petit is a lightweight Cardano wallet built as a Chrome Extension. This project is a collaborative learning initiative focused on gaining hands-on experience with web extension development and blockchain technology.

## Purpose

This project serves as a practical learning environment to deepen our technical knowledge through real-world development experience.

## Learning Objectives

Through the development of Petit, we aim to gain proficiency in:

- **Chrome Extension Development** - Understanding the architecture, implementation, and deployment of browser extensions
- **Quality Assurance** - Establishing testing procedures and verification workflows for extension-based applications
- **Git & GitHub Workflow** - Practicing branch management, code reviews, and collaborative development processes
- **API Integration** - Implementing third-party APIs such as CoinGecko for real-time data
- **UI/UX Development** - Building intuitive and responsive user interfaces
